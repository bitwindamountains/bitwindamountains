# Hi, I'm Clint

Junior full-stack developer in Cebu, Philippines. I build small tools that make my own day easier, and apps for everyday problems I see around me: collecting rent, taking orders over Messenger, keeping receipts.

## How I work

- **Tests come with the code.** Every project has automated tests, and most run them in CI on every push.
- **Money is stored exactly.** Apps that handle payments use exact decimals or whole centavos, never floating point.
- **Docs say what's done and what isn't.** Each README has a status line, including what still needs work.
- **You can try it.** Where free hosting allows, the project has a live demo.
